# LBW Sports Shop

Cinematic showcase site for **LBW Sports Shop** (`lbwsports.in`) — Hanamkonda & Mancherial.

Orders and enquiries go to **WhatsApp** (no online checkout).

## Stack

- Next.js + TypeScript + Tailwind
- GSAP ScrollTrigger + Framer Motion
- React Three Fiber hero (realistic willow bat, cricket balls, shuttlecocks)
- Local product catalogue with WhatsApp enquire CTAs

## Develop

```bash
npm install
npm run dev
```

## Deploy

Point `lbwsports.in` DNS to Vercel / Cloudflare Pages / Netlify after `npm run build`.
